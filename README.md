# Kids Games Learning Platform

## فكرة المشروع
منصة تعليمية تفاعلية للأطفال تعتمد على الألعاب لتعليم أسس البرمجة بطريقة ممتعة وتدريجية.

## الهدف
تجهيز طفل من المبتدئ إلى مستوى أكثر تقدماً عبر:
- الأوامر الأساسية
- التكرار والحلقات
- الشروط والمنطق
- التفكير وحل المشكلات
- المشاريع الصغيرة

## بنية المشروع
- `index.html` : نقطة الدخول الرئيسية للمنصة
- `pages/index/` : الصفحة الرئيسية
- `pages/games/` : قسم الألعاب وبطاقاته
- `pages/maze/` : لعبة المتاهة
- `pages/draw/` : لعبة الرسم
- `pages/gas/` : لعبة مهندس الغاز الذكي
- `pages/lesson/` : الدروس التعليمية
- `pages/common.css` : الأنماط المشتركة
- `pages/common.js` : حفظ تقدم اللاعب

## إضافة لعبة
أضف صفحة اللعبة داخل `pages/` ثم أضف عنصرًا إلى `gameCatalog` في `pages/common.js` يتضمن المفتاح والعنوان والرمز والرابط وعدد المستويات واللون. سيظهر العنصر تلقائيًا في قسم الألعاب، ويدخل عدد مستوياته في ملخص التقدم.

## التشغيل
افتح الملف التالي في المتصفح:
- `index.html`

أو استخدم خادم ثابت مثل:
- `python -m http.server 8000`

ثم افتح:
- http://localhost:8000/

## ربط حساب Google وحفظ بيانات المستخدم
1. أنشئ مشروعًا في Firebase، وأضف تطبيق Web، ثم انسخ إعداداته إلى `firebase-config.json`.
2. من Authentication فعّل مزود Google، وأضف `localhost` ونطاق GitHub Pages مثل `username.github.io` إلى Authorized domains.
3. أنشئ قاعدة Firestore، وانشر قواعد `firestore.rules`.
4. شغّل التطبيق عبر HTTP/HTTPS، ثم سجّل الدخول بحساب Google واختر الدور.

يُحفظ ملف الحساب والدور والتقدم تحت UID الخاص بحساب Google، ويُستعاد التقدم عند الدخول من جهاز آخر. إعداد Firebase مطلوب لتفعيل Google والتخزين السحابي؛ تسجيل الدخول المحلي التجريبي يبقى محفوظًا على الجهاز فقط. لا تضع أسرارًا أو كلمات مرور في `firebase-config.json`. المسارات معدّة للعمل مع GitHub Pages داخل مجلد المستودع.

## المرحلة الحالية

- تم إضافة نظام حفظ تقدم الأطفال
- تم توسيع مسار التعلم في الصفحة الرئيسية
