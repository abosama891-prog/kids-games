# Kids Games Learning Platform

## فكرة المشروع
منصة تعليمية تفاعلية للأطفال تعتمد على الألعاب لتعليم أسس البرمجة بطريقة ممتعة وتدريجية.

## الهدف
تجهيز طفل من المبتدئ إلى مستوى أكثر تقدماً عبر:
- الأوامر الأساسية
- التكرار والحلقات
- الشروط والمنطق
- التفكير وحل المشكلات
- المشاريع الصغيرة

## بنية المشروع
- `index.html` : نقطة الدخول الرئيسية للمنصة
- `pages/index/` : الصفحة الرئيسية
- `pages/games/` : قسم الألعاب وبطاقاته
- `pages/maze/` : لعبة المتاهة
- `pages/draw/` : لعبة الرسم
- `pages/lesson/` : الدروس التعليمية
- `pages/common.css` : الأنماط المشتركة
- `pages/common.js` : حفظ تقدم اللاعب

## إضافة لعبة
أضف صفحة اللعبة داخل `pages/` ثم أضف عنصرًا إلى `gameCatalog` في `pages/common.js` يتضمن المفتاح والعنوان والرمز والرابط وعدد المستويات واللون. سيظهر العنصر تلقائيًا في قسم الألعاب، ويدخل عدد مستوياته في ملخص التقدم.

## التشغيل
افتح الملف التالي في المتصفح:
- `index.html`

أو استخدم خادم ثابت مثل:
- `python -m http.server 8000`

ثم افتح:
- http://localhost:8000/

## المرحلة الحالية
- الصفحة الرئيسية منقّحة إلى نسخة احترافية أكثر
- تم تنظيم المشروع في مجلدات
- تم إضافة نظام حفظ تقدم الأطفال
- تم توسيع مسار التعلم في الصفحة الرئيسية
